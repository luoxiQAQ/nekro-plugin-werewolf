基于 Nekro-Agent 的完整狼人杀游戏插件，支持 9 人局、AI 玩家补位、AI 复盘、自动化流程控制。

> 本插件移植自 AstrBot 插件 [astrbot_plugin_werewolf](https://github.com/libin99527/astrbot_plugin_werewolf)（作者 miao，MIT 协议），已将框架层适配为 Nekro-Agent，游戏逻辑与原版保持一致。感谢原作者的工作。

## ✨ 功能特性

- 🎮 **完整游戏流程**：夜晚行动（狼人、预言家、女巫、猎人）、白天发言、投票放逐、PK 环节
- 🔢 **编号系统**：自动分配 1-9 号，群名片临时改为编号，游戏结束后恢复
- 🤐 **智能禁言**：夜晚全员禁言，发言时临时解除（需 Bot 有群管理权限，可配置关闭）
- 💬 **遗言机制**：第一晚被狼杀、投票放逐均有遗言，被毒无遗言
- 🔫 **猎人技能**：被狼杀或投票放逐可开枪带走一人，被毒不能开枪
- 🤖 **AI 玩家**：人不够？AI 来凑！支持人类 + AI 混合对局或纯 AI「赛博斗蛐蛐」
- 📝 **AI 复盘**：游戏结束后自动生成复盘报告，评选 MVP 和划水王
- ⚙️ **高度可配置**：玩家数量、角色配置、各阶段超时、AI 模型组等
- 📊 **平票处理**：自动进入 PK 环节，二次投票决定放逐

## 📋 游戏规则

- **默认配置**：9 人局 = 3 狼人 + 预言家 + 女巫 + 猎人 + 3 平民
- **狼人胜利**：好人数量 ≤ 狼人数量，或神职全部出局
- **好人胜利**：所有狼人被放逐出局

## 🚀 安装

1. 打开 Nekro-Agent 的 Web 管理面板，进入插件管理页面
2. 选择从 Git 仓库安装（添加云端插件），填入本仓库地址：

   ```
   https://github.com/luoxiQAQ/nekro-plugin-werewolf
   ```

3. 安装完成后重载插件，日志出现 `插件加载成功` / `[狼人杀] 插件已加载` 即安装成功

**前置要求**：

- Nekro-Agent 已配置 OneBot V11 适配器（NapCat 等）并接入 QQ 群
- 玩家需要添加 Bot 为好友才能收到夜晚行动的私聊消息
- 可选：Bot 为群管理员/群主时可使用禁言与群名片功能（可在配置中关闭）

## 📖 命令列表

命令无需前缀，直接在群里发送即可；也支持 Nekro 命令系统（如 `/创建房间`）。

### 基础命令（群聊）

| 命令 | 说明 | 权限 |
|------|------|------|
| `创建房间` | 创建游戏房间 | 所有人 |
| `加入房间` / `加入` | 加入游戏 | 所有人 |
| `开始游戏` | 开始游戏 | 房主 |
| `结束游戏` | 强制结束游戏 | 房主 |
| `游戏状态` | 查看游戏状态 | 所有人 |
| `狼人杀帮助` | 显示帮助（图片菜单） | 所有人 |
| `（名字）加入` | 添加 AI 玩家（如 `小咪加入`） | 默认所有人，可配置仅管理员 |
| `踢出AI 名字` | 移除指定 AI 玩家 | 所有人 |

### 夜晚命令（私聊 Bot）

| 命令 | 角色 | 示例 |
|------|------|------|
| `办掉 编号` | 狼人 | `办掉 3` |
| `密谋 消息` | 狼人 | `密谋 我们刀3号` |
| `验人 编号` | 预言家 | `验人 5` |
| `救人` | 女巫 | `救人` |
| `毒人 编号` | 女巫 | `毒人 7` |
| `不操作` | 女巫 | `不操作` |
| `开枪 编号` | 猎人 | `开枪 2` |

### 白天命令（群聊）

| 命令 | 权限 | 示例 |
|------|------|------|
| `发言完毕` | 当前发言者 | `发言完毕` |
| `遗言完毕` | 被杀玩家 | `遗言完毕` |
| `开始投票` | 房主 | `开始投票` |
| `投票 编号` / `投票 @某人` | 所有存活玩家 | `投票 4` |

## ⚙️ 配置说明

在 Nekro 管理面板的插件配置页修改，修改后重载插件生效：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `total_players` | 9 | 总玩家数（需等于角色数之和，否则回退默认配置） |
| `werewolf_count` / `seer_count` / `witch_count` / `hunter_count` / `villager_count` | 3/1/1/1/3 | 各角色数量 |
| `timeout_wolf` 等 | 120 | 各阶段超时时间（秒），投票超时 >30 秒时会在剩 30 秒时提醒 |
| `ban_duration_days` | 30 | 出局玩家禁言时长（天） |
| `enable_group_ops` | true | 是否使用禁言/群名片/临时管理员（需要 Bot 群管理权限；关闭后纯流程进行） |
| `enable_ai_review` | true | 游戏结束后是否生成 AI 复盘 |
| `ai_review_model_group` | 空 | AI 复盘使用的模型组，留空用默认 |
| `ai_review_prompt` | 空 | 自定义复盘提示词（支持 `{winning_faction}`、`{game_data}` 占位符） |
| `ai_player_model_group` | 空 | AI 玩家决策使用的模型组，留空用默认 |
| `ai_join_need_admin` | false | 添加 AI 玩家是否需要 Nekro 管理员权限 |

[群聊]

## ⚠️ 注意事项

1. **私聊收不到？** 玩家需先添加 Bot 为好友；也可私聊发送 `查角色` 查看身份。
2. **群操作权限**：禁言、改群名片需要 Bot 是群管理员或群主；权限不足时操作会静默失败，游戏流程不受影响。不希望 Bot 动用群管理权限时，可在配置中关闭 `enable_group_ops`。
3. **AI 玩家与复盘**使用 Nekro 当前模型组（可在插件配置中指定专门模型组），会产生一定 token 消耗。
4. 游戏状态存储在内存中，Bot 重启后进行中的游戏会丢失（房间会自动恢复群名片与禁言状态的清理逻辑仅限当次运行，重启前建议先 `结束游戏`）。
5. 平票处理：首次平票进入 PK 发言 + 二次投票；PK 仍平票则本轮无人出局。

## 🧩 与原版（AstrBot）的差异

- 命令提示不再显示框架前缀（Nekro 下命令为裸文本或 `/命令`）
- AI 玩家 / AI 复盘改为通过 Nekro 的模型组直接调用大模型
- 新增 `enable_group_ops` 开关：无群管理权限的 Bot 也能带局（无禁言效果）
- 新增 `ai_join_need_admin` 开关（原版固定仅管理员可添加 AI 玩家）
- 修复原版 `游戏状态` 命令遍历玩家列表的崩溃问题
